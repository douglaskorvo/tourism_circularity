# Codebook

Each retrieved passage (±160 characters around the matched term; full review when needed) was coded on five fields. Coder 1 coded all 1,176 passages; Coder 2 independently coded a stratified random 25% subsample (296 passages).

| Field | Values | Decision rule |
|---|---|---|
| `relevante` | S / N | **S** when the passage describes, in the intended sense, a practice or attribute of responsible production or consumption linked to the supplier, the visitor or the destination. **N** when the term is used in another sense, e.g. "waste of money", "a rubbish place", "needs repairs" as maintenance, "packaging" only as a delivery complaint, "artisanal" as a mere quality adjective with no reference to how goods are made. |
| `estrategia` | see list below | Main strategy described in the passage, which may differ from the automatic category. "Não se aplica" when `relevante` = N. |
| `estrategia_2` | see list below (optional) | Second strategy, only if the passage clearly describes two. |
| `quem` | Fornecedor / Visitante / Destino-comunidade / Indeterminado | Who performs the practice: the reviewed supplier, the visitor (own consumption choice), or the community/destination. |
| `valencia` | Positiva / Negativa / Neutra | The reviewer's attitude towards the practice (not the overall rating). |

## Strategy categories (Kirchherr et al., 2017; Potting et al., 2017)

| Category | Definition |
|---|---|
| R0–R2 Recusar / repensar / reduzir | Avoiding or reducing material use, packaging, disposables, food waste |
| R3 Reutilizar | Reuse, second-hand trade, antiques, reuse of inputs |
| R4 Reparar | Repair or mending services and practices |
| R5–R6 Restaurar / remanufaturar | Restoration or reconditioning of goods or buildings, including adaptive reuse of heritage |
| R7 Repropor / upcycling | New function for discarded material |
| R8 Reciclar | Material recycling |
| R9 Recuperar (energia) | Energy recovery |
| Cadeia local | Local producers, inputs or food; fair trade; productive cooperatives; organic |
| Artesania | Manual production; artisans as producers |
| Sustentabilidade declarada | Generic sustainable or ecological claim with no identifiable strategy |
| Não se aplica | Passage not relevant |

A review counts as reporting a circular practice when at least one relevant code (main or second) falls in R0–R8.
